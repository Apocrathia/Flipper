# .agents/

A light install of the context engine (`.agents` protocol), sized for a
one-script repo: a root router (`../AGENTS.md`) plus two context modules.

| File                                         | Holds                                        |
| -------------------------------------------- | -------------------------------------------- |
| [`context/facts.md`](context/facts.md)       | Device, firmware lineage, sources, dead ends |
| [`context/pitfalls.md`](context/pitfalls.md) | Traps that have actually been hit            |

No rules, skills, personas, or task intake here. A one-script repo needs
none of those; the broader context engine covers them where they exist.

The context is living. Fix a module in the same change that makes it wrong,
or leave a `<!-- drift: ... -->` note.
